# PaintAire

This is a brand / marketing site in the **PaintAire** ecosystem — the operating system for
painting contractors. It is **not** a PaintAire platform service.

Platform docs live in the [`jmohouse6/ecosystem`](https://github.com/jmohouse6/ecosystem) repo
(`MISSION.md`, `ECOSYSTEM.md`). Any lead capture routes into the PaintAire-backed intake (CRM),
and customer-facing pages use the contractor's brand as the primary identity.
